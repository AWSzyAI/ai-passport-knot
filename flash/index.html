给卡片刷入 Knot

用电脑上的 Chrome 或 Edge，插一根 USB 线，点一下按钮就装好。整个过程大约一分钟，不用装任何软件。

这个浏览器不能直接连 USB 设备。请在电脑上用 Chrome 或 Edge 打开这一页；手机、Safari 和 Firefox 都不行。

  1. 开机

    按住卡片侧面的电源键约半秒，屏幕亮起。没电的话先充十来分钟。卡片关机时电脑认不到它。

  2. 插线

    用能传数据的 USB‑C 线连到电脑。只能充电的线不行。

  3. 安装

    点下面的按钮，在弹出的列表里选 USB JTAG/serial debug unit，再点「连接」。

    请用 https 打开这一页。

    第一次从官方固件换成 Knot：勾选「清除设备」。以后升级：不要勾，配对和还没同步的记录都会保留。

  4. 回到手机

    卡片重启后屏幕显示 KNOT。打开 iPhone 上的 Knot App 点「同步」，第一次会请你输入卡片屏幕上的 6 位数字完成配对。

列表里找不到设备

确认卡片已经开机、屏幕是亮的；换一根数据线或换一个 USB 口；关掉其他可能占用串口的程序（比如 Arduino、串口助手）后重试。

装完卡片显示 Storage error

卡片里留着旧固件的数据。重新安装一次并勾选「清除设备」。

勾了「清除设备」以后手机连不上

清除会删掉卡片里的配对信息。在 iPhone「设置 › 蓝牙」里找到 Knot‑xxxxxx，点 ⓘ 选「忽略此设备」，再回 Knot App 同步并输入新的 6 位数字。

想用命令行刷

下载 最新的固件，执行 esptool.py --chip esp32c3 write_flash 0x0 knot-firmware-*-full.bin。这样会清掉配对。
